# Mini E-Commerce React App

This project is a mini e-commerce application built for Betterway - SDE Assignment

## Features
- Product listing with stock status
- Search by product name
- Filter by category
- Sort by price (Low to High, High to Low)
- Add to cart, remove items, update quantity
- Cart total items and total price
- Mocked product data (no backend)

## Tech Stack
- React
- JavaScript
- CSS

## Notes
This project focuses on clean component structure, proper state management, and handling edge cases as per the assignment requirements.
